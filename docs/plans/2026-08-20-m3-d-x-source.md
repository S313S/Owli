# M3-d X Source Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 实现 X recent search、受控 SQLite 用量台账、周预算软护栏、平台硬闸与 429 BACKOFF，并把过滤后的基线证据写入既有 Store。

**Architecture:** `app/sources/x.py` 只负责 X HTTP、字段转换、预算决策与结构化事件；所有 SQLite 语句集中在 `app/store/` 的固定方法。schema 通过只前进迁移加入两张系统运行态表，`SOURCE_SPEC` 留在 X 源模块供后续自动发现。

**Tech Stack:** Python 标准库、SQLite STRICT/WAL、pytest、urllib 假 HTTP 注入、Decimal 金额计算。
