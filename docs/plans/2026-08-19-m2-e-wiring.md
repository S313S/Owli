# M2-e Plan-driven Wiring Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Replace the M0 fixed chain with one plan-driven runtime from request through reviewed plan, Scheduler execution, interventions, and final report.

**Architecture:** Add a RuntimeCoordinator between FastAPI and Scheduler. It alone owns real clock/timer, adapter task conversion, state projection, card auto-confirm, artifact discard, and finalization; Scheduler remains a pure injected state machine and mini.py no longer contains a competing fixed workflow.

**Tech Stack:** Python 3.11, FastAPI, asyncio, SQLite, pytest, existing RoutedAdapter/Scheduler/plan modules.
