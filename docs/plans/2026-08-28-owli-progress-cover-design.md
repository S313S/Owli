# Owli 进展状态首图设计

## 目标

制作一张面向非技术伙伴、运营和产品经理的 Owli 项目进展首图。首图优先回答“当前进展到哪了”，而不是完整解释系统架构。

## 受众

- 运营、产品经理、非技术协作伙伴。
- 可能从 README、项目介绍页或社交分享图第一次接触 Owli 的人。
- 需要快速判断项目成熟度，而不是理解 M0-M7、双引擎内部协议或具体代码实现的人。

## 信息边界

- 可以表达：产品方向、方案验证、工作台骨架、证据可靠度、真实全链路稳定性。
- 不表达：内部路径、私有文档、Feishu 链接、运行日志、commit、测试数量、账号状态、预算、真实客户信息。
- 不把“进行中”画成“已完成”。
- 不用退出码作为任何完成证明。

## 推荐方案

采用“进度雷达 / 状态总览图”。

画面中心是 Owli，周围展示五个状态模块：

1. 产品方向已定：完成。
2. 双引擎方案验证：完成。
3. 本地工作台骨架：已跑通。
4. 证据可靠度底座：已建立。
5. 真实无人值守全链路：进行中。

底部补一句下一步：传输韧性与报告链路稳定化。

## 视觉口径

- 整体像一张项目状态海报，不像工程架构图。
- 采用轻量动效：状态点依次亮起，最后停在“进行中”。
- 主色不做单一蓝紫色堆叠，使用深色背景、暖橙主标识、绿色完成、蓝色验证、紫色进行中。
- 文案短，避免密集说明。

## 产物

- HTML/CSS/SVG 源文件，便于后续修改。
- PNG 静态图，用于 README 和社交分享。
- 可选 GIF 动效图，用于 README 或项目介绍页。
