# M3-h-fix-5 实现计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 修复章生成缺失全卷采集上下文，以及段级、章级 lint 共用重试预算的问题。

**Architecture:** 先从冻结的 Plan 一次性派生全卷采集清单，章提示词读取该清单，系统装配对 comparison / cross_validation 确定性补齐全部采集路径。`generate_plan` 保留现有段级 lint 前移循环，在段级收敛后进入独立章级 lint 循环；章级错误按消息头定位到具体章并只强制重生成这些章。

**Tech Stack:** Python 3.13、asyncio、pytest、现有 PlanSegmentWorkspace 与 plan lint。
