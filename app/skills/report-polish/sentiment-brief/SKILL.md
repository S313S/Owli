# 舆情简报

读者是要决定「要不要回应、回应什么」的人。他们没时间读分析，要的是**现在外面在说什么、
哪些说法值得当回事**。全篇比咨询体短，一级标题就用 `sections` 里那八个词。

> 产出形态借自 skainguyen1412/social-media-research-skill（MIT）：情感分布 / 排名 /
> 时间线 / 原文引用四件。取数与口径全是 Owli 自己的。

## 总体倾向

**一句话说清外面的总体调门**，然后跟一组数：主题极性表里提及量最大的三个主题，
各自的正向词命中数与负向词命中数。

这里最容易犯的错是把命中数说成百分比。口径是词表命中的**条数**，
所以只能写「562 条证据里 138 条命中主题词，其中 X 条同时含正向词、Y 条含负向词」，
**不能**写「X% 的用户持正面态度」。这一条不许违反，读者会照着这句话做判断。

这一节末尾固定加一句人话置信度提示（共用规则 6.5.2）：

> 本报告结论的把握度为**低 / 中 / 高**，主要因为……

多数说法只有单一来源时，把握度就写「低」，理由用人话说清楚。**不许在这一节写 SINGLE / PASS / WEAK / CONFLICT 或「253/274」这类内部口径**，留给附录。

## 正面的说法 / 负面的说法 / 争议与冲突 / 用户诉求

四块同一个写法：**先一句概括（主语 + 判断 + 量级），然后按共用规则 §5.6 的
主题段五步，一个主题一段**——这一块里有几个主题就写几段，别把所有说法揉成一段。

主题从给你的态度表里取（`attitude_by_topic`），表里没有的主题不许自己造。
一块里主题超过四个就只写前四个，剩下的收进末尾一句「另有零星提及……」。

四块写的都是**用户说了什么**。平台分布、等级分布、交叉验证分布这类描述取数过程的表
不许进这四块，「被引」「采集条数」「采集量」这些取数口径词也不许出现在这四块的正文里；
样本短板归总体倾向末尾那句把握度和附录（见共用规则 §4.5）。

四块的分法：
- **正面**：命中正向词、且说的是产品本身好在哪。
- **负面**：命中负向词的抱怨与吐槽。
- **争议与冲突**：`crossref_mix` 里 CONFLICT 的主张，以及同一件事正反两种说法并存的。
  **这一块必须把两边都写出来**，不许只取一边。
- **用户诉求**：用户明确要求「希望能……」「什么时候出……」的。没有就写「本轮未采到明确诉求」，
  不许硬凑。

原文引用只从 A/B 级证据里挑。C 级的可以提及但不单独成引。

四块各自的限定写在那一块最后一句里，**限定一句话说完**，不要另起「假设与不确定性」小节——那一节全篇只在附录写一次（共用规则 §5.1）。

## 时间线

**这一节必有。** 把 `timeline` 表原样列出来（一行一期），**不要画图**——
页面没有图表渲染器，画了读者只会看到一块裸代码（共用规则 §6）。
表上面先写那句结论——是在升温、在降温、还是有一个明显的拐点。
如果 `timeline` 表没给到（发布时间覆盖不足三成），就在这一节如实写「本轮证据里有发布时间的
不足三成，不足以判断趋势」，**不许拿部分数据强行画趋势**。

## 需要回应的点

不是「建议」，是**「如果不回应会怎样」**。每条两行：

```
1. **要回应的点**（一句）
   为什么值得回应：波及面 N 条 / 等级 X / 是否有冲突；不回应的风险一句
```

按波及面排序。只有 C 级或单源撑着的，标注「先核实再决定是否回应」。

## 附录

「假设与不确定性」写在这一节，全篇只此一处（共用规则 §5.1）。
按共用规则第 7 条五件事写，其中口径那件必须写明主题极性表为什么不是百分比。
