# 舆情简报

读者是要决定「要不要回应、回应什么」的人。他们没时间读分析，要的是**现在外面在说什么、
哪些说法值得当回事**。全篇比咨询体短，一级标题就用 `sections` 里那八个词。

> 产出形态借自 skainguyen1412/social-media-research-skill（MIT）：情感分布 / 排名 /
> 时间线 / 原文引用四件。取数与口径全是 Owli 自己的。

## 总体倾向

**一句话说清外面的总体调门**，然后跟一组数：主题极性表里提及量最大的三个主题，
各自的正向词命中数与负向词命中数。

这里最容易犯的错是把命中数说成百分比。口径是词表命中的**条数**，
所以只能写「562 条证据里 138 条命中主题词，其中 X 条同时含正向词、Y 条含负向词」，
**不能**写「X% 的用户持正面态度」。这一条不许违反，读者会照着这句话做判断。

⚠️ **第二个容易犯的错：把海外的条数算进「国内大家」那个数**（§SEL-4，用户 09-18 拍板）。
题面问「国内大家怎么看 X」时，程序注入的那行「已编码评论 N 条」**已经按地域拆成两侧**
（「国内 a 条：正…；海外社区 b 条：正…」）。你这一句总体调门要**照着国内那一侧说**，
⛔ 别把两侧加起来当成国内的数，也⛔ 别把海外那一侧悄悄省掉不提（共用规则 §5.7.2 末条）。

这一节末尾固定加一句人话置信度提示（共用规则 6.5.2）：

> 本报告结论的把握度为**低 / 中 / 高**，主要因为……

⛔ **不许再写「多数说法只有单一来源所以低」**（旧规则，§RPT-8 废止）：那句在本项目
语料上几乎恒真——一条主张记的往往就是「某平台有用户反馈 X」，结构上只会挂一条证据，
照它写每份简报开篇都在劝读者别信。
**那个档位不是你定的**：程序按**每条关键发现**自己引的证据算（几个独立出处 / 几个平台 /
最强等级 / 落在编码表哪一格有多少条），整篇取各条的中位档。你那句话里的档位必须写
程序算出来的那一个，对不上当轮打回；「主要因为……」那半句写**哪几条强、哪几条弱**
的人话理由。⛔ 不许写「多数说法只有一个来源所以低」——那句在本项目语料上几乎恒真，
等于每份报告开篇都劝读者别信（共用规则 §6.5.2 里有真稿例句，照那个形状写）。

**把握度判「低」的那几条发现，标题不得大过证据**（共用规则 §6.5.2′，程序当轮核）：
标题里不许出现「普遍 / 大多数 / 主流 / 集体 / 广泛」这类普遍化断言词，
发现行里要交代证据规模或范围（「两篇公众号文章」「同一个帖子下的两条评论」
「本轮样本里」）。判「高」的那几条照旧正常写，不必加限定。

**不许在这一节写 SINGLE / PASS / WEAK / CONFLICT 或「253/274」这类内部口径**，留给附录。

## 正面的说法 / 负面的说法 / 争议与冲突 / 用户诉求

四块同一个写法：**先一句概括（主语 + 判断 + 量级），然后按共用规则 §5.6 的
主题段五步，一个主题一段**——这一块里有几个主题就写几段，别把所有说法揉成一段。

主题从给你的态度表里取（`attitude_by_topic`），表里没有的主题不许自己造。
一块里主题超过四个就只写前四个，剩下的收进末尾一句「另有零星提及……」。

四块写的都是**用户说了什么**，而且是题面问的那个对象。池里两种带栏的源待遇不一样
（完整规则见共用规则 §5.7）：带「**旁证·对照实体**」栏的源 ⛔ 不进这四块，
要提就在那一块末尾一句「对照与旁证」里说（§5.7.1）；带「**海外社区**」栏的源
✅ **进得了**这四块（用户 2026-09-18 拍板放行），**但引用它的那一句要让读者看出
这是海外社区的声音**——点名平台或点明是海外，写法示例见 §5.7.2。
⛔ **例外只有一处：总体倾向那句合并统计的数字不许把海外算进国内。**
那句话只有一个数，标不了出身。程序给的口径串已经把国内与海外**分开写**，
你照它给的数说，⛔ 别自己把两侧加起来当成国内的数（§5.7.2 末条）。
平台分布、等级分布、交叉验证分布这类描述取数过程的表
不许进这四块，「被引」「采集条数」「采集量」这些取数口径词也不许出现在这四块的正文里；
样本短板归总体倾向末尾那句把握度和附录（见共用规则 §4.5）。

四块的分法：
- **正面**：命中正向词、且说的是产品本身好在哪。
- **负面**：命中负向词的抱怨与吐槽。
- **争议与冲突**：`crossref_mix` 里 CONFLICT 的主张，以及同一件事正反两种说法并存的。
  **这一块必须把两边都写出来**，不许只取一边。
- **用户诉求**：用户明确要求「希望能……」「什么时候出……」的。没有就写「本轮未采到明确诉求」，
  不许硬凑。

原文引用从 A/B/C 级证据里挑（D 级与未评级不引），出处行必须标等级；C 级原声只作例子，不拿它单独撑判断。

四块各自的限定写在那一块最后一句里，**限定一句话说完**，不要另起「假设与不确定性」小节——那一节全篇只在附录写一次（共用规则 §5.1）。

## 时间线

**这一节必有。** 把 `timeline` 表原样列出来（一行一期），**不要画图**——
页面没有图表渲染器，画了读者只会看到一块裸代码（共用规则 §6）。
表上面先写那句结论——是在升温、在降温、还是有一个明显的拐点。
如果 `timeline` 表没给到（发布时间覆盖不足三成），就在这一节如实写「本轮证据里有发布时间的
不足三成，不足以判断趋势」，**不许拿部分数据强行画趋势**。

## 需要回应的点

不是「建议」，是**「如果不回应会怎样」**。每条两行：

```
1. **要回应的点**（一句）
   为什么值得回应：波及面 N 条 / 等级 X / 是否有冲突；不回应的风险一句
```

按波及面排序。**这一节受「弱证据不撑强建议」那道门禁管**（跟建议节同一道）：
一条里引的角标全是单源孤证，就不许当「要回应的点」写，机械降级到「值得进一步验证的方向」，
降级的那几条排在这一节最后。形态按共用规则 §6.5.4「降级区写成什么样」照做——
另起 `### 值得进一步验证的方向` 小标题，或把「值得进一步验证的方向：」写在条目号和 `**`
之后紧挨着。降级条目的第二行照旧写「先核实什么才能决定要不要回应」。
⛔ 只在句子里写一句「先核实再决定是否回应」不算降级，程序不认，会被原样打回。

## 附录

「假设与不确定性」写在这一节，全篇只此一处（共用规则 §5.1）。
按共用规则第 7 条五件事写，其中口径那件必须写明主题极性表为什么不是百分比。

**代表原声表由程序接在这一节，你一个字都不要写。** 但它的数据仍然投给你——
正文里的原声**引用块**照共用规则 §5.6 步骤 4 写。
⚠️ 某一格没有可引的原话就是真的没有（表已按等级筛过，A/B/C，D 不进），照 §5.6 那条分情况诚实写：
真没有原话才说没有；有原话、等级是 C 的照引并标「等级 C」，⛔ 不许写「未截取到评论正文」。
⛔ 不许去够 D 级证据或帖子标题凑——两样都会被程序闸原样打回。
⛔ 只是**整张表**不许摆进正文（同一张表出现两次，读者第二次只会跳过）。
