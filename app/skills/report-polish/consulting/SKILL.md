# 调研报告（咨询体）

读者是拿结论去用的人：运营、产品、老板。他们要的是「所以呢」，不是「我们做了什么」。
全篇按下面五节写，一级标题就用 `sections` 里那五个词，一字不改。

## 执行摘要

先写一段 SCQA，**不超过 150 字**，四句话：

- 背景：这件事的处境是什么（一句）。
- 冲突：出现了什么变化或问题（一句）。
- 问题：于是要回答的问题是什么（就是调研问题本身，一句）。
- **答案：结论是什么**（一句，带量级，带角标）。

然后是 **3–5 条关键发现**，每条一行，格式固定：

```
1. 【A】结论句（主语+判断+量级）[S12][S18]
```

方括号里是这条发现最强证据的等级（A/B/C）。三条以下说明你没读透，六条以上说明你没归纳。
关键发现是全篇最重要的部分——如果读者只看这一块就走了，他也该拿到该拿的东西。

最后固定一句人话置信度提示（共用规则 6.5.2）：

> 本报告结论的把握度为**低 / 中 / 高**，主要因为……

摘要正文里不许出现 SINGLE / PASS / WEAK / CONFLICT 这些内部口径词，也不许写「253/274」这类方法论读数——那些留给附录。

## 关键发现

上面每条发现在这里展开一节，二级标题，顺序固定四步，**一步都不许跳**：

1. **行动式标题**（二级标题本身就是那句结论，不是话题）。
   标题之下先按**共用规则 §5.6 的主题段五步**把这个主题交代清楚
   （覆盖面 → 强度 → 2–3 条原声 → 对提问方意味着什么），再往下走第 2 步。
2. **一张数据表或一张图**——先按选图三步法确认这张图要说的结论句，再选形态。
   表下面标一行 `n= · 口径 · 来源角标`。
3. **三到五句解读**：这张表为什么支持上面那个标题。只解读，不搬运——不要把表里每一行
   再用文字念一遍。
4. **反证或限定**：这条结论在什么情况下不成立、哪些证据指向相反方向、样本有什么局限。
   **限定一句话说完**，不要另起「假设与不确定性」小节——那一节全篇只在附录写一次（共用规则 §5.1）。
   这一步只在这条结论真的撑不住时写；撑得住就把话说完整，别为了免责补一句。

**这一节的每条发现都必须是关于调研对象的**（谁在什么场景下夸什么、骂什么），
第 2 步那张主表也得是讲对象的表。平台分布、等级分布、交叉验证分布、时间分布这四张
描述取数过程的表**不许出现在这一节**，「被引」「采集条数」「采集量」这些取数口径词
也不许出现在这一节的正文里——它们的位置在附录（见共用规则 §4.5）。

## 论据与数据

把正文用到的确定性数据表在这里集中列一遍，每张表带标题（行动式）、`n`、口径、来源角标。
表里的数一个都不许改。正文引用过的表这里必须有，没引用过的表不必都放。

## 建议

按「影响 × 把握度」排序：影响大且把握足的排最前。每条建议两行：

```
1. **建议一句话**（做什么，不是"应该重视什么"）
   依据：回指第 N 条发现；把握度：高/中/低（理由一句）
```

把握度取决于撑着它的那条发现的证据等级和交叉验证结论。**弱证据不撑强建议**——
只有 C 级或全是 SINGLE 撑着的想法，写成「值得进一步验证的方向」，别写成行动建议。

## 附录

「假设与不确定性」写在这一节，全篇只此一处（共用规则 §5.1）。
按共用规则第 7 条的五件事写：方法与样本、缺失清单（人话）、各表口径（含主题极性表
为什么不是百分比）、信息源清单（角标 → 标题 / 链接 / 等级）。
